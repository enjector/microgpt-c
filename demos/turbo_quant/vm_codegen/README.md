# TurboQuant: VM Codegen Quality Benchmark

This directory executes an evaluation on the **TurboQuant Vector Quantizer** within an environment mandating deterministic output structures: the MicroGPT-C Virtual Machine DSL code generation framework.

## Benchmark Objectives
Where the *Shakespeare* benchmark prioritises measuring sheer text throughput, the VM Codegen module assesses mathematical degradation. TurboQuant compresses 32-bit features using stochastic approximations and quantized residuals (4 bits total per value). Since generating nested `{ }` loops and functional signatures requires near-perfect context representations, this benchmark measures whether precision loss "breaks" the model's logical output flow.

## Build & Run
```bash
# Build the targets
cd ../../../build
make tq_vm_codegen_base tq_vm_codegen_tq

# Run
./tq_vm_codegen_base
./tq_vm_codegen_tq
```

*Note: The script currently defaults to parsing test prompts sequentially with `cfg.num_steps=0` (inference only).*

## Observations
The compression mathematics (MSE clustering codebook paired with the 1-bit QJL offset projection) robustly retained logical continuity. 
At infinite memory scales, the 8x squashing allowed the Top-1 Context Router inside the MSA sequence pool to repeatedly hit highly viable vectors. The `MsaPool` chunk injection generated byte-exact conditional structures relative to its base confidence. Shrinking logical states to edge-friendly byte widths proves stable for DSL generation limits alongside pure generative prose.
