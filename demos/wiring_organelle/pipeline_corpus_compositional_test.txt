#   Axis 1 (10): Compose 2 primitives that DO NOT co-occur in any of
#                the 20 anchor families. Tests "novel pair" composition.

#                type-mismatch.

# Format mirrors pipeline_corpus_held_out.txt:
#   // <prompt>
#   # EXPECTED: <comma-separated primitive names>
#   # REFERENCE: <function_name in wiring_references.c>
#   # INPUT_ORDER: <comma-separated nouns matching the reference's S[0..N] slots>
#   ---
#
# The INPUT_ORDER annotation (Phase 6b, Stream E) tells the harness how to
# map the reference's positional inputs onto the binder's noun-keyed
# signature inputs. Without this, a topologically-correct graph whose
# signature inputs were reordered by the binder would score against the
# wrong reference slots.
